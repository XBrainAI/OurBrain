订单管理系统 Demo
===================
版本：Phase 1 - v1.0.0
生成时间：2026-06-21

技术栈：Vue 3 + Element Plus + Vue Router 4（CDN 加载，无需构建）

启动方式：
  Windows：双击 start.bat
  或命令行：cd demo && python -m http.server 8080
  浏览器访问：http://localhost:8080

页面说明：
  - 首页概览（/dashboard）：统计卡片 + 最近订单
  - 订单列表（/order-list）：搜索筛选 + 分页表格 + 状态变更 + 取消订单
  - 新建订单（/order-create）：选择客户 + 添加产品 + 自动计算
  - 订单详情（/order-detail/:id）：基本信息 + 产品明细 + 操作日志

数据说明：
  - 预置 5 个客户、5 个产品、5 个订单（含各状态）、12 条操作日志
  - 所有数据存储在内存中，页面刷新后恢复初始状态
  - 订单编号格式：ORD-YYYYMMDD-XXXX

标注系统：
  - 点击右上角「标注」开关打开标注面板
  - L1 页面说明、L2 区域标注、L3 元件标注
  - 水滴形编号标记与面板双向联动

Demo 限制（Phase 1）：
  - 仅实现核心功能骨架，不含精细校验和复杂联动
  - 操作日志仅供查看，不支持独立管理
  - 取消操作不涉及实际资源释放（库存等）
