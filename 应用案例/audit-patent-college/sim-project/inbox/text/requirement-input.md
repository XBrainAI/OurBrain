# PM 需求详版

> 项目：高校存量专利AI盘活转化匹配平台（patent-college）
> 基础：基于 `requirement-scenario-brief.md` 场景简述扩展
> 状态：Phase 1 阶段产出，由 AI 与 PM 对话澄清后形成

## 1. 业务背景

### 1.1 行业痛点

国家推进专利转化专项行动以来，全国高校沉睡专利量级达千万级，但产学研转化效率极低：

- **供给侧失衡**：高校实验室海量专利处于"申请即沉睡"状态，缺乏面向产业需求的二次分级与商业化路径
- **需求侧错配**：中小制造企业普遍反映"找不到合适技术"，人工检索匹配命中率不足 40%
- **流程链路断裂**：从专利清洗、需求匹配、洽谈撮合到补贴申报的链路分散在多个系统中，缺乏统一平台
- **地方转化痛点**：广州聚集中山大学、华南理工、暨南大学、华南师范、广东工业等大量理工科高校，广东省产学研转化需求集中爆发，但地方补贴申报与转化跟踪长期手工化

### 1.2 价值主张

构建"清洗-匹配-洽谈-转化-补贴"全生命周期的智能撮合平台，通过 AI 大模型将专利技术与企业工艺需求多维度精准对齐，把人工匹配命中率从 40% 提升至 70% 以上，让高校沉睡专利变为产业升级的可调用资源池。

### 1.3 项目范围

- 仅覆盖"高校存量专利"盘活场景，不涉及企业自有专利申请
- 仅服务广东省内高校与广东省内企业作为首批试点，逐步扩展至大湾区
- AI 匹配模型调用外部供应商接口，平台内不训练模型
- 补贴申报仅生成材料，不直连政府申报系统

## 2. 用户角色

| 角色 ID | 角色名 | 职责说明 | 关键诉求 |
|---------|--------|---------|---------|
| `college-research` | 高校科研处 | 清洗盘点本校存量专利；审核企业转化申请；管理专利产业化分级 | 看到本校专利盘活率 KPI；批量清洗提效 |
| `enterprise-tech` | 企业技术经理 | 发布技术需求；查看匹配专利；推进转化洽谈 | 快速找到适配专利；少打扰无效匹配 |
| `transfer-broker` | 转化中介 | 撮合高校与企业交易；跟进转化全流程；代办补贴申报 | 全流程透明；撮合佣金可追溯 |

### 2.1 角色权限边界

- 高校科研处：本校专利 CRUD + 全量匹配库只读 + 转化审核入口
- 企业技术经理：仅可见"匹配中/洽谈中"状态的专利，不可见沉睡/清洗中
- 转化中介：可读全量数据，仅可更新洽谈/已转化阶段的状态与合同信息

## 3. 核心功能

### 3.1 模块清单

| 模块 | 功能点描述 | 优先级 |
|------|----------|--------|
| 专利清洗分级 | 高校科研处对沉睡专利批量清洗，按"实验室/中试/产业化"三级标签分类 | P0 |
| 智能匹配引擎 | 调用 AI 大模型对企业需求与专利库多维度匹配，输出匹配度评分与排序结果 | P0 |
| 撮合洽谈流程 | 企业发起洽谈、中介跟进跟进、状态流转跟踪（沉睡→清洗→匹配→洽谈→已转化） | P0 |
| 转化合同管理 | 中介录入转化合同信息，自动生成权属与收益分配模板 | P1 |
| 补贴一键申报 | 已转化专利自动套用地方补贴政策模板，生成申报材料包 | P1 |
| 全流程跟踪 | 时间轴展示专利从清洗到转化的每个节点，含 SLA 警告（洽谈超 90 天自动回退） | P0 |

### 3.2 AI 匹配维度

匹配引擎从以下 5 个维度对企业需求与专利库进行加权评分：

- **工艺维度**：企业工艺描述 ↔ 专利技术摘要（语义相似度）
- **参数维度**：关键技术参数（温度/压力/精度区间）匹配度
- **产业链维度**：上下游产业链位置对齐度
- **预算维度**：企业预算区间与专利成熟度估算成本匹配
- **地域维度**：高校所在城市与企业所在城市的政策协同度

## 5. 业务规则

### 5.1 状态流转规则

```
沉睡 (dormant) ──[清洗]──> 清洗中 (cleaning) ──[清洗完成]──> 匹配中 (matching)
                                                              │
                                                              ├──[企业发起洽谈]──> 洽谈中 (negotiating)
                                                              │                       │
                                                              │                       ├──[合同签订]──> 已转化 (transferred)
                                                              │                       │
                                                              │                       └──[90天未签约]──> 回退匹配中
                                                              │
                                                              └──[匹配度<60%]──> 不推送企业
```

### 5.2 业务约束

| 约束 | 规则 | 触发场景 |
|------|------|---------|
| 失效专利剔除 | 失效专利或权属纠纷专利自动过滤，不进入匹配池 | 清洗分级阶段 |
| 匹配度阈值 | 匹配度低于 60% 的专利不推送至企业 | AI 匹配完成后 |
| 洽谈超时回退 | 同一专利洽谈超过 90 天未签约，自动回退至匹配中 | 定时任务每日扫描 |
| 洽谈并发上限 | 同一专利同时仅可与 3 家企业洽谈 | 进入洽谈前校验 |
| 企业可见性 | 企业技术经理仅可见"匹配中/洽谈中"状态的专利 | 列表查询时过滤 |

### 5.3 权限矩阵

| 操作 | 高校科研处 | 企业技术经理 | 转化中介 |
|------|----------|------------|---------|
| 查看全量专利 | ✅ | ❌（仅匹配中/洽谈中） | ✅ |
| 批量清洗 | ✅ | ❌ | ❌ |
| 发起匹配 | ✅ | ✅（仅自有需求） | ❌ |
| 进入洽谈 | ❌ | ✅ | ✅ |

| 申报补贴 | ❌ | ❌ | ✅ |
