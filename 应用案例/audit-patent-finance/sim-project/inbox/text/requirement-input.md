> 项目：知识产权金融一体化智能评估质押系统（patent-finance）
> 来源：基于 `requirement-scenario-brief.md` + 与 PM 对话澄清扩展
> 阶段：阶段 1 · 完整需求（AI 详版）

## 1. 业务背景

### 1.1 行业现状
广东省知识产权质押贷款规模年增长率约 30%，2025 年全省专利质押融资备案金额突破 800 亿元。然而在快速增长的背后，行业存在三大结构性矛盾：

- **估值标准化缺失**：银行普遍沿用传统资产评估思路，依靠评估师人工经验判断专利价值，单案评估周期 7-15 个工作日，主观性过强，同类专利在不同评估师手中估值差异可达 40%。
- **风控工具断层**：质押登记后缺乏对专利法律状态、年费缴纳、无效诉讼的持续监控，质押物失效发现往往滞后于风险暴露，银行不良率攀升。
- **处置流转不畅**：违约后专利处置依赖线下撮合，缺少对接技术交易所的标准化流转通道，处置周期长达 6-12 个月，回收率不足 50%。

### 1.2 政策驱动
广东省 2024 年出台《知识产权质押融资风险补偿政策》，对本地企业贴息 2%、银行风险补偿 30%，但政策匹配与申领流程线上化程度低，企业漏享率约 35%。

### 1.3 价值主张
构建**知识产权金融一体化智能评估质押系统**，通过：
- 法律 / 产业 / 市场 / 营收**四维 AI 估值模型**，将单案评估周期压缩至 1 个工作日
- 质押全流程**数字化台账**，自动监控法律状态、年费、无效诉讼
- 多专利**组合融资智能测算**，提升综合授信额度
- 对接**广东技术交易所**的处置流转通道
- 广东**贴息政策智能匹配**引擎

最终实现"企业融资易、银行风控稳、政策享得到"的三方共赢。

## 2. 用户角色

| 角色 ID | 角色名 | 职责说明 | 数据范围 |
|---------|--------|----------|----------|
| financing-manager | 企业融资经理 | 发起质押申请、上传专利清单、跟进放款进度、申请贴息 | 仅本企业案件 |
| bank-risk | 银行风控 | 审核质押案件、监控风险预警、执行放款、对接处置 | 本行全部案件 |
| assessor | 评估师 | 执行 AI 估值与组合测算、出具评估报告 | 全部案件（只读+更新） |

## 3. 核心功能

### 3.1 AI 四维估值引擎
- 法律维度：专利法律状态、剩余保护期、无效诉讼历史
- 产业维度：技术领域景气度、产业链位置、技术替代风险
- 市场维度：同族专利布局、许可实施记录、市场交易可比案例
- 营收维度：基于企业财务数据反推专利实施收益贡献

### 3.2 质押全流程数字化台账
- 登记管理：对接国家知识产权局质押登记接口
- 年费监控：自动提醒年费到期，超期预警
- 权属变更：专利权人变更同步触发质押合同复审
- 无效风险监控：监控无效诉讼公告，自动触发风险预警

### 3.3 多专利组合融资测算
- 支持多专利打包质押
- 组合估值自动加权计算
- 综合授信额度测算（不超过组合估值 70%）
- 单专利 vs 组合质押方案对比

### 3.4 专利处置与流转撮合
- 违约案件自动进入处置队列
- 对接广东技术交易所挂牌通道
- 处置进度可视化跟踪
- 处置收益自动分配结算

### 3.5 广东贴息政策智能匹配
- 自动校验广东本地企业条件
- 匹配省/市/区三级贴息政策
- 贴息申领材料一键生成
- 贴息到账跟踪

### 3.6 风险预警中心
- 专利无效诉讼预警
- 年费超期预警
- 专利权属变更预警
- 评估价值偏差预警（市场可比案例跌幅 > 20%）

## 5. 业务规则

### 5.1 状态流转规则
```
已申请（applied） → 评估中（assessing） → 已审批（approved） → 已登记（registered） → 已放款（disbursed） → 已还款（repaid）
```
- 已申请 → 评估中：仅评估师可触发，调用 AI 估值
- 评估中 → 已审批：仅银行风控可触发，弹出审批意见弹窗
- 已审批 → 已登记：系统自动调用国知局质押登记接口
- 已登记 → 已放款：仅银行风控可触发
- 已放款 → 已还款：系统根据还款计划自动流转

### 5.2 质押金额约束
- 单笔质押贷款金额 ≤ 专利评估价值 × 70%
- 多专利组合质押：组合估值 × 70% 上限
- 超出 70% 时表单高亮错误，禁止提交

### 5.3 重复质押约束
- 已在质押中（state ∈ {assessing, approved, registered, disbursed}）的专利不可重复质押
- 提交时校验，重复时提示"该专利已在案件 <case_no> 中质押"

### 5.4 权限规则
| 操作 | financing-manager | bank-risk | assessor |
|------|-------------------|-----------|----------|
| 新增案件 | ✓（本企业） | ✗ | ✗ |
| 查看案件 | ✓（本企业） | ✓（本行） | ✓（全部） |
| 启动评估 | ✗ | ✗ | ✓ |
| 审批 | ✗ | ✓ | ✗ |
| 放款 | ✗ | ✓ | ✗ |
| 导出台账 | ✗ | ✓ | ✗ |

### 5.5 贴息匹配规则
- 企业注册地须在广东省内
- 案件状态须为"已放款"
- 单企业年度贴息上限 100 万元
