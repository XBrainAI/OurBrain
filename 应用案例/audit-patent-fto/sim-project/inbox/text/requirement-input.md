# PM 需求详版

> 来源：`requirement-scenario-brief.md`（PM 输入原始归档）
> 场景：全球多区域 FTO 智能合规风控系统（patent-fto）

## 1. 业务背景

广州及珠三角密集的中小型外贸出口工厂近年频发欧美、东南亚专利侵权诉讼，单案赔付动辄上百万美元，部分企业因一款产品被诉而丧失整个海外市场。传统 FTO（Freedom to Operate，自由实施尽职调查）依赖海外律所人工比对，单次报价 5-15 万元人民币、周期 3-6 周，且缺失「产品技术特征 vs 专利权利要求」的逐要素自动比对能力，工厂一旦收到海外律师函往往已无力回旋。

本项目目标是构建面向跨境出口工厂的多区域 FTO 智能风控平台，将全球多局专利检索、AI 技术特征比对、三级风险等级可视化与规避设计输出整合到统一工作台，让企业 IPR、FTO 分析师、外贸经理三类角色在产品立项与出海前完成低成本快速 FTO 筛查与深度商事尽调。

价值主张：
- 极速简版 FTO 报告 24 小时内出，深度商事报告 5 工作日内出
- 高风险强制输出规避设计建议方可交付，杜绝「带雷出海」
- 全球多局专利实时数据库覆盖美国 USPTO、欧盟 EPO、日本 JPO、东南亚 IPO、中东专利局
- 同一产品同一市场 90 天内不可重复发起深度 FTO，避免资源浪费

## 2. 用户角色

| 角色标识 | 中文名 | 职责说明 |
|---------|--------|---------|
| ipr | 企业 IPR | 发起 FTO 分析任务，指定目标市场与产品，跟进风险处置与交付进度；可见全部数据 |
| fto-analyst | FTO 分析师 | 执行技术特征逐要素比对，输出三级风险等级与规避设计建议，生成报告；不可创建/删除任务 |
| export-manager | 外贸经理 | 仅查看本部门产品的 FTO 风险状态与已交付报告，协调规避设计落地，无创建/编辑权限 |

## 3. 核心功能

### 3.1 全球多局专利实时检索
- 接入 USPTO / EPO / JPO / 东南亚各国 IPO / 中东专利局公开数据
- 支持按产品名称、技术关键词、申请人、专利分类号（IPC/CPC）检索
- 检索结果按相关度、申请日、法律状态排序

### 3.2 AI 技术特征逐要素侵权比对
- 输入：产品技术特征清单 + 目标市场专利权利要求
- 输出：逐要素对比表（特征文本 vs 权利要求文本 + 是否等同/相同/不同）
- 标注风险贡献度，输出三级风险等级（low / medium / high）

### 3.3 三级风险可视化与规避设计
- 风险等级：低（low）/ 中（medium）/ 高（high）
- 高风险必须输出规避设计建议（特征替换方案）方可交付
- 可视化矩阵：风险等级 × 市场区域 × 产品线

### 3.4 双报告生成
- **极速简版报告**：24 小时内出，含风险等级 + 关键专利清单 + 处置建议
- **深度商事报告**：5 工作日内出，含逐要素比对表 + 规避设计 + 法律意见书草稿

### 3.5 竞品专利动态预警
- 订阅竞品申请人/IPC 分类号新公开专利
- 按周推送预警邮件与站内消息
- 预警命中后可一键发起新 FTO 分析

### 3.6 FTO 分析任务管理
- 三阶段状态流转：待分析 → 分析中 → 低/高风险 → 已交付
- 90 天内同产品同市场去重
- 权限分级：IPR 全权限 / 分析师 读+更新 / 外贸经理 仅读本部门

## 5. 业务规则

### 5.1 状态流转
```
待分析 (pending) → 分析中 (analyzing) → 低风险 (low_risk) / 高风险 (high_risk) → 已交付 (delivered)
```

### 5.2 权限规则
- 企业 IPR：create / read / update / delete / export，scope=all
- FTO 分析师：read / update / export，scope=all
- 外贸经理：read，scope=own（仅本部门产品）

### 5.3 业务约束
- 同一产品同一目标市场 90 天内不可重复发起深度 FTO（极速简版可重复发起）
- 高风险必须输出规避设计建议方可交付
- 极速简版报告 24 小时内出
- 深度商事报告 5 工作日内出
- 竞品专利动态按周推送预警（每周一 09:00 推送）
- 已交付状态不可再编辑

### 5.4 报告交付条件
- 低风险：分析师提交报告即可交付
- 高风险：必须先填写规避设计建议（特征替换方案）方可点击交付按钮
- 已交付：导出按钮激活，可下载 PDF 报告
