# PM 需求详版

> 来源：`inbox/text/requirement-scenario-brief.md`（PM 输入原始归档）
> 场景：AIGC 软件算法类数字专利专项管理平台
> 适用：Demora Phase 2 设计、Phase 3 评审、Phase 3 交付验收

## 1. 业务背景

### 1.1 行业痛点

随着生成式 AI、工业软件、边缘算法快速渗透实体经济，相关专利申请量年增 100%。算法类专利与机械/化学类专利在权属判定、创新点挖掘、FTO（Freedom To Operate）比对、开源协议冲突识别上存在显著差异：

- 现有通用专利工具无法解析代码、算法流程图，创新逻辑挖掘依赖人工撰写；
- AI 生成物激增后，企业普遍存在算法专利保护缺失、权属不清问题；
- 同一算法被多人重复申请专利，开源代码与商业专利边界模糊；
- 软件专利 FTO 比对缺少 API/算法架构/功能模块层面的专项工具。

### 1.2 价值主张

为研发型企业、知识产权部门、专利代理机构提供「**算法专利解析 — 权属判定 — FTO 比对 — 申请跟踪**」一体化的数字专利管理平台，将传统人工撰写专利文档的 5-10 天周期压缩至 1 天内，同时降低权属争议风险。

### 1.3 适用场景

- 生成式 AI 模型训练算法、推理服务算法
- 工业软件控制算法、PLC 程序
- 边缘算法、物联网设备算法
- AI 辅助生成内容（AIGC）的权属确权与存证

## 2. 用户角色

| 角色标识 | 中文名 | 主要职责 | 权限范围 |
|---------|--------|---------|---------|
| `ai-engineer` | AI 工程师 | 上传代码/算法，补充技术细节，提交专利 | 仅可创建和查看自己提交的专利（scope: own） |
| `ipr` | 企业 IPR | 管理算法专利，审核权属判定，触发 FTO 比对 | 全部专利的增删改查导出（scope: all） |
| `agent` | 代理师 | 基于解析结果撰写申请文件，跟踪申请状态 | 全部专利的查看/更新/导出（scope: all） |

### 2.1 角色协作流程

```
AI 工程师 ──提交代码──> IPR 审核权属 ──> 代理师撰写申请 ──> IPR 标记授权
   (P03)                 (P02)              (P02)              (P02)
```

## 3. 核心功能

### 3.1 代码/算法多模态专利解析

- 接收代码资产（文本/文件）和算法类型（生成式 AI/工业软件/边缘算法/物联网算法）
- 异步执行代码解析，提取创新逻辑（创新点列表）
- 输出算法流程图（Mermaid）和创新点描述

### 3.2 AI 生成物专利权属智能判定

- 权属类型：人工发明 / AI 辅助 / 纯机器生成
- **合规规则**：纯机器生成内容不可作为专利发明人（合规校验失败时禁止提交）
- IPR 审核确认权属判定结果

### 3.3 软件专利 FTO 专项比对

- 比对维度：API 接口、算法架构、功能模块
- 命中高风险 API 须输出规避方案
- 开源协议冲突识别（GPL/AGPL/LGPL/MIT/Apache）

### 3.4 开源代码专利风险筛查

- 检测代码资产中的开源组件
- 识别协议冲突（如 GPL 衍生作品申请专利的合规风险）
- **合规规则**：开源协议冲突时禁止提交申请

### 3.5 算法专利布局与申请跟踪

- 状态流转：已提交 → 解析中 → 分析中 → 已申请 → 已授权
- 申请文件跟踪（代理师撰写）
- 申请进度可视化

## 4. 页面列表

| 页面 ID | 页面名称 | 类型 | 路由 | 主要功能 |
|---------|---------|------|------|---------|
| P01 | AIGC 专利列表 | crud_list | `/aigc-patents` | 展示企业全部算法专利，支持搜索/分页/新增/触发解析 |
| P02 | AIGC 专利详情 | detail_view | `/aigc-patents/:id` | 展示专利详情、代码资产、解析结果、FTO 比对、权属判定，触发分析/审核/标记授权 |
| P03 | 代码上传解析表单 | form_page | `/aigc-patents/form` | AI 工程师提交新算法专利，含专利号/算法类型/代码资产/权属类型等字段 |

### 4.1 P01 AIGC 专利列表

- 顶部搜索区：专利号、算法类型、权属类型、开发者、申请人、状态（6 个搜索条件）
- 操作栏：新增专利按钮（需 `aigc-patent:create` 权限）
- 数据表格：展示专利列表，算法类型/权属类型/状态使用状态标签
- 行内操作：查看详情、AI 解析按钮（状态为「已提交」时可触发）
- 底部分页：标准分页组件

### 4.2 P02 AIGC 专利详情

- 详情头部：描述列表展示基本信息
- 代码资产区：展示代码内容与算法流程图（Mermaid）
- 解析结果区：展示创新逻辑挖掘、FTO 比对、开源协议冲突
- 操作按钮区：触发分析、审核权属、标记授权（按状态条件显示）

### 4.3 P03 代码上传解析表单

- 表单字段：专利号、算法类型、代码资产、权属类型、开发者、申请人
- 必填校验：除代码资产外均为必填
- 业务规则：
  - 选择「纯机器生成」权属类型时弹出合规风险提示
  - 同一算法（同算法类型+同代码哈希）不可重复申请
- 操作按钮：提交（校验通过后跳转列表）、取消（返回上一页）

## 5. 业务规则

### 5.1 状态流转

```
已提交 (submitted) ──AI解析──> 解析中 (parsing)
解析中 (parsing)   ──触发分析──> 分析中 (analyzing)
分析中 (analyzing) ──IPR审核权属──> 已申请 (filed)
已申请 (filed)     ──标记授权──> 已授权 (granted)
```

### 5.2 权限规则

- AI 工程师：仅查看/创建自己提交的专利（`scope: own`）
- IPR：全部专利的增删改查导出（`scope: all`），独占审核权属操作
- 代理师：全部专利的查看/更新/导出（`scope: all`），仅可见 P01/P02

### 5.3 合规规则

- 纯机器生成内容不可作为专利发明人（合规校验）
- 同一算法不可重复申请专利（唯一性校验）
- 开源协议冲突时禁止提交申请（前置校验）
- FTO 比对命中高风险 API 须输出规避方案
