# AIGC软件算法类数字专利专项管理平台需求

## 背景
生成式 AI、工业软件、边缘算法专利申请量年增 100%，算法专利权属、侵权、布局规则特殊；现有通用专利工具无法解析代码、算法流程，企业普遍存在算法专利保护缺失、权属不清问题。

## 核心功能
- 代码/算法多模态专利解析（创新逻辑挖掘）
- AI 生成物专利权属智能判定（人工/AI辅助/纯机器生成）
- 软件专利 FTO 专项比对（API/算法架构/功能模块）
- 开源代码专利风险筛查与协议冲突识别
- 算法专利布局与申请跟踪

## 用户角色
- AI工程师：上传代码/算法，补充技术细节
- 企业IPR：管理算法专利，审核权属判定
- 代理师：基于解析结果撰写申请

## 业务规则
- 纯机器生成内容不可作为专利发明人（合规校验）
- 同一算法不可重复申请专利
- 开源协议冲突时禁止提交申请
- FTO 比对命中高风险 API 须输出规避方案
