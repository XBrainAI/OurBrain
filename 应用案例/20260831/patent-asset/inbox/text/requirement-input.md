# 专利资产全生命周期数字化价值运营管理平台 · 详版需求文档

> 来源：inbox/documents/audit-patent-asset-requirement-scenario-brief.md（PM 上传文档）+ AI 澄清扩展

## 1. 业务背景

传统专利台账仅围绕年费缴纳做登记管理，无法量化单件专利与专利组合的资产价值。企业在融资、上市、质押融资等资本动作中缺少标准化的专利资产底稿，投行与银行尽调时需要临时手工整理材料，周期长、口径乱。同时，大量授权后闲置的专利难以盘活交易，缺乏对接产业需求方的撮合通道。

本平台定位为「专利资产全生命周期数字化价值运营管理平台」，将专利从授权登记、年费监控、AI 估值、组合战略分析、产业撮合到质押/转让退出的全过程纳入统一数字底稿，让专利资产可量化、可预警、可交易、可尽调。

核心痛点：
1. 台账只管年费，专利价值说不清，融资上市时拿不出资产底稿；
2. 估值靠经验拍脑袋，缺法律/技术/市场/营收四维标准化模型；
3. 闲置专利沉睡，缺少对接产业需求方的撮合通道；
4. 质押/转让状态分散在合同与邮件里，全生命周期状态无法跟踪；
5. 管理层没有一屏总览资产规模与风险的高管驾驶舱。

## 2. 用户角色

| 角色 | 职责说明 | 级别 |
|------|---------|------|
| 企业IPR | 维护专利资产台账，跟进年费缴纳与估值更新，发起缴费与信息修正 | A级 |
| 资产经理 | 评估资产价值，确认季度估值，主导产业撮合与投融资/上市尽调导出 | B级 |
| 银行风控 | 查看质押专利价值与风险预警，跟踪质押物状态变化 | B级 |
| 高管（C级） | 查看高管驾驶舱总览资产规模、估值分布与风险预警（驾驶舱仅对 C 级角色开放） | C级 |

## 3. 核心功能

1. **全流程专利资产台账与年费监控**：专利资产登记（专利号/类型/技术领域/权利人/关键日期），年费到期前 30 天自动预警，逾期未缴自动置为失效，支持台账关键字/状态/技术领域组合筛选。
2. **行业定制 AI 估值模型**：法律/技术/市场/营收四维打分模型，每季度自动生成一版估值，需资产经理确认后生效；确认前展示四维得分明细。
3. **专利组合战略分析与投融资尽调一键导出**：组合等级结构（A/B/C/D）与技术领域分布，战略四象限矩阵（核心防御/增值运营/盘点出售/放弃退役），按范围一键导出尽调包并留痕。
4. **产业专利撮合通道与高管可视化驾驶舱**：撮合意向登记（转让/许可/质押融资），状态推进（初步接触→尽调中→签署意向→成交/搁置）；高管驾驶舱展示在管资产、总估值、风险资产、年度成交额与风险预警列表。
5. **质押/转让状态全生命周期跟踪**：质押登记/转让记录全量跟踪，质押中专利不可转让（需先解除质押），支持解除质押操作与风险提示。

## 5. 业务规则

1. **年费预警**：年费到期前 30 天，专利资产状态自动置为「年费预警」，并进入驾驶舱风险预警列表。
2. **逾期失效**：年费逾期未缴，专利资产状态自动置为「失效」，失效专利不可发起质押/转让/撮合。
3. **季度估值确认**：估值每季度更新一次，新生成估值为「待确认」状态，需资产经理确认后生效为「已确认」；驾驶舱与台账展示最新已确认估值。
4. **质押转让互斥**：质押中专利不可转让，新建转让记录时若专利处于质押中，必须先解除质押（表单阻断并提示）。
5. **驾驶舱权限**：高管驾驶舱仅对 C 级角色（高管）开放，其他角色导航中不可见。
6. **撮合状态机**：初步接触 → 尽调中 → 签署意向 → 成交/搁置，只能按顺序推进，搁置为终态。

## 6. 验收标准

1. 台账页展示不少于 10 条专利资产记录，覆盖有效/年费预警/失效/质押中状态（S-1~S-14 可验证）。
2. 筛选区关键字、状态、技术领域组合筛选后，表格行与统计条计数同步重算，往返往返一致（D10 筛选往返探针可验证）。
3. 新建专利弹窗可打开、必填校验、提交后台账新增一行并计数变化（D3 弹窗闭环 + D6 业务状态变化可验证）。
4. 缴纳年费后对应专利状态由「年费预警」回到「有效」，统计条预警计数减一（D6 可验证）。
5. 估值中心存在「待确认」估值记录，点击确认后状态变更为「已确认」（D6 可验证）。
6. 新建转让记录选择「质押中」专利时被阻断并出现不可转让提示（P038/D6 可验证）。
7. 尽调一键导出后生成一条导出留痕记录（D6 可验证）。
8. 每页均有 L1 页面说明、≥3 个 L2 区域标注、可交互元件类型 L3 全覆盖（D8/D9/D10 可验证）。
9. 高管驾驶舱为默认路由，切换到资产经理等非 C 级角色后驾驶舱导航不可见（P027/D5 可验证）。
10. 全站无 console error / 404（D0 可验证），弹窗均可正常关闭（D3 可验证）。
