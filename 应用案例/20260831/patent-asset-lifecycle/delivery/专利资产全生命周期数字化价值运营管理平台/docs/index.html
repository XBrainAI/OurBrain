专利资产全生命周期数字化价值运营管理平台 — 需求详版

来源：inbox/text/requirement-scenario-brief.md（PM 场景简报）

一、业务背景

传统专利台账仅管理年费，无法量化资产价值。企业在融资、上市、质押等场景缺少标准化专利资产底稿，闲置专利难以盘活交易，专利资产停留在"档案"而非"可运营资产"的层面。本平台面向企业 IPR、资产经理、银行风控与 C 级高管，提供覆盖专利全生命周期的数字化价值运营能力：台账管理、年费监控、AI 四维估值、组合战略分析、质押转让跟踪与产业撮合，输出标准化数字底稿支撑投融资尽调。

二、用户角色

角色 职责
企业IPR专员 维护专利资产台账，跟进年费与估值，发起质押/转让，发布撮合需求
资产经理 评估资产价值，确认季度估值，管理专利组合，对接融资/上市尽调
银行风控 查看质押专利价值与风险预警，评估质押授信
C级高管 通过高管驾驶舱查看资产全景、行业分布与风险预警

三、核心功能

  • 全流程专利资产台账与年费监控：到期前 30 天自动预警，逾期未缴自动置为失效
  • 行业定制 AI 估值模型：法律/技术/市场/营收四维评分，每季度更新并经资产经理确认
  • 专利组合战略分析与投融资尽调一键导出：防御/进攻/运营三种战略组合，生成融资/上市/质押底稿
  • 产业专利撮合通道：按目标产业与技术关键词匹配可交易专利
  • 质押/转让状态全生命周期跟踪：质押中专利不可转让，解除质押后方可交易
  • 高管可视化驾驶舱：仅对 C 级角色开放

ID 名称 类型 路由 主要功能

P08 高管驾驶舱 dashboard /cockpit 资产全景、行业分布、风险预警、维度切换（C级专属）

五、业务规则

  • 年费到期前 30 天自动预警；逾期未缴自动将专利置为"逾期失效"
  • 估值每季度更新一次，需经资产经理确认后方生效
  • 质押中专利不可转让，需先解除质押
  • 高管驾驶舱仅对 C 级角色开放，非 C 级角色不可见
  • 筛选/搜索必须按控件当前值全量重算行集，计数与可见行保持一致

六、验收标准

  • 台账可搜索、按类型/状态/行业筛选，结果计数与表格行数一致
  • 新增专利、质押登记、发起转让、新建组合、发布需求可通过弹窗表单完成并即时反映到列表
  • 缴费登记、估值确认/驳回、解除质押、取消转让等操作即时更新状态与统计指标
  • 8 个页面均可通过侧栏导航切换，默认路由为 P01 专利台账
  • 所有弹窗支持关闭按钮、遮罩点击与 ESC 关闭
  • 高管驾驶舱仅在角色切换为 C 级高管后可见

// router/guard.ts
export function requireAuth(to: RouteLocation, from: RouteLocation, next: Function) {
  const user = useUserStore();
  if (!user.isLoggedIn) {
    next({ path: "/login", query: { redirect: to.fullPath } });
    return;
  }
  // 检查角色权限
  const allowedRoles = to.meta?.allowedRoles as string[] | undefined;
  if (allowedRoles && !allowedRoles.some(r => user.roles.includes(r))) {
    next({ path: "/403" });
    return;
  }
  next();
}

// utils/request.ts
instance.interceptors.response.use(
  (response) => response.data,
  (error) => {
    const { response } = error;
    if (!response) {
      message.error("网络异常，请检查网络后重试");
      return Promise.reject(error);
    }
    const { status, data } = response;
    switch (status) {
      case 401: redirectToLogin(); break;
      case 403: message.error("您无权访问此功能"); break;
      case 404: message.error("资源不存在或已被删除"); break;
      case 422: message.error(data.message || "业务校验失败"); break;
      case 500: message.error("系统繁忙，请稍后重试"); break;
      default: message.error(data.message || "未知错误");
    }
    return Promise.reject(error);
  }
);
