## Task Flow（任务流，BPMN 2.0）

> **业界标准**：BPMN 2.0（Business Process Model and Notation）
> **关注点**：用户完成业务任务的操作步骤序列，按角色分 Pool/Lane。
> **图例**：`(( ))` 事件 / `( )` 任务 / `{ }` 网关 / 实线=Sequence Flow / 虚线=Message Flow

### BPMN 任务流图

```mermaid
flowchart TD
    Start((用户登录))
    subgraph Pool1["企业IPR专员"]
        Pool1_T1("浏览专利资产")
        Pool1_T2("查看专利资产详情")
        Pool1_T1 --> Pool1_G1{"通过?"}
        Pool1_G1 -->|是| Pool1_T2
        Pool1_G1 -->|否| Pool1_End((结束))
        Pool1_T3("浏览估值记录")
        Pool1_T2 --> Pool1_G2{"通过?"}
        Pool1_G2 -->|是| Pool1_T3
        Pool1_G2 -->|否| Pool1_End((结束))
        Pool1_T4("浏览年费记录")
        Pool1_T3 --> Pool1_G3{"通过?"}
        Pool1_G3 -->|是| Pool1_T4
        Pool1_G3 -->|否| Pool1_End((结束))
        Pool1_T5("浏览质押登记")
        Pool1_T4 --> Pool1_G4{"通过?"}
        Pool1_G4 -->|是| Pool1_T5
        Pool1_G4 -->|否| Pool1_End((结束))
        Pool1_T5 --> Pool1_Done((任务完成))
    end
    subgraph Pool2["资产经理"]
        Pool2_T1("查看看板")
        Pool2_T1 --> Pool2_Done((任务完成))
    end
    subgraph Pool3["银行风控"]
        Pool3_T1("浏览撮合需求")
        Pool3_T1 --> Pool3_Done((任务完成))
    end
    subgraph Pool4["C级高管"]
        Pool4_T1("执行业务操作")
    end
    Start --> Pool1_T1
    Pool1_Done -.->|交付专利资产/估值记录| Pool2_T1
    Pool2_Done -.->|交付| Pool3_T1
    Pool3_Done -.->|交付| Pool4_T1
    Pool4_Done --> End((业务完成))
    Evt1{{"专利资产: 授权有效 → 即将到期"}}
    Evt2{{"专利资产: 即将到期 → 逾期失效"}}
    Evt3{{"专利资产: 授权有效 → 质押中"}}
```

### 角色任务清单（BPMN Pool/Lane 视角）

| 角色 (Pool) | 任务 (Task) | 触发条件 | 关联页面 | 关联实体 | 交付物 |
|------|------|----------|----------|---------|--------|
| 企业IPR专员 | 浏览专利资产 | 登录后进入工作台 | 专利资产列表页(patent-ledger) | 专利资产、年费记录、估值记录 | 业务数据 |

| 银行风控 | 浏览撮合需求 | 登录后进入工作台 | 撮合需求列表页(match) | - | 业务数据 |

### 跳转模式说明

- **列表 → 详情**：用户在列表页点击行项目，跳转到详情页查看完整信息
- **列表 → 表单**：用户在列表页点击"新建"按钮，跳转到表单页录入数据
- **详情 → 列表**：用户在详情页点击"返回"，回到列表页
- **任意页 → 主页**：用户点击面包屑或 Logo，返回主页
- **退出登录**：用户点击退出按钮，终止会话

## 分支流程

### 分支一：专利资产状态流转

```mermaid
graph TD
    S0["授权有效"]
    S1["即将到期"]
    S2["逾期失效"]
    S3["质押中"]
    S4["转让中"]
    S5["已转让"]
    S0 -->|年费到期前30天自动预警| S1
    S1 -->|逾期未缴自动置为失效| S2
    S0 -->|质押登记完成| S3
    S3 -->|解除质押| S0
    S0 -->|发起转让| S4
    S4 -->|转让成交| S5
    S4 -->|转让取消| S0
```

- **授权有效 -> 即将到期**：触发=年费到期前30天自动预警，条件=距离年费到期日不超过30天且尚未缴费
- **即将到期 -> 逾期失效**：触发=逾期未缴自动置为失效，条件=超过年费到期日仍未缴纳
- **授权有效 -> 质押中**：触发=质押登记完成，条件=-
- **质押中 -> 授权有效**：触发=解除质押，条件=-
- **授权有效 -> 转让中**：触发=发起转让，条件=专利未处于质押中
- **转让中 -> 已转让**：触发=转让成交，条件=-
- **转让中 -> 授权有效**：触发=转让取消，条件=-
