## Task Flow（任务流，BPMN 2.0）

> **业界标准**：BPMN 2.0（Business Process Model and Notation）
> **关注点**：用户完成业务任务的操作步骤序列，按角色分 Pool/Lane。
> **图例**：`(( ))` 事件 / `( )` 任务 / `{ }` 网关 / 实线=Sequence Flow / 虚线=Message Flow

### BPMN 任务流图

```mermaid
flowchart TD
    Start((用户登录))
    subgraph Pool1["品牌方IPR"]
        Pool1_T1("查看看板")
        Pool1_T2("浏览侵权线索")
        Pool1_T1 --> Pool1_G1{"通过?"}
        Pool1_G1 -->|是| Pool1_T2
        Pool1_G1 -->|否| Pool1_End((结束))
        Pool1_T3("浏览维权案件")
        Pool1_T2 --> Pool1_G2{"通过?"}
        Pool1_G2 -->|是| Pool1_T3
        Pool1_G2 -->|否| Pool1_End((结束))
        Pool1_T4("浏览跨境规则模板")
        Pool1_T3 --> Pool1_G3{"通过?"}
        Pool1_G3 -->|是| Pool1_T4
        Pool1_G3 -->|否| Pool1_End((结束))
        Pool1_T5("查看看板")
        Pool1_T4 --> Pool1_G4{"通过?"}
        Pool1_G4 -->|是| Pool1_T5
        Pool1_G4 -->|否| Pool1_End((结束))
        Pool1_T5 --> Pool1_Done((任务完成))
    end
    subgraph Pool2["维权律师"]
        Pool2_T1("执行业务操作")
    end
    subgraph Pool3["监测分析师"]
        Pool3_T1("查看存证记录详情")
        Pool3_T1 --> Pool3_Done((任务完成))
    end
    Start --> Pool1_T1
    Pool1_Done -.->|交付维权案件/跨境规则模板| Pool2_T1
    Pool2_Done -.->|交付| Pool3_T1
    Pool3_Done --> End((业务完成))
    Evt1{{"侵权线索: 待存证 → 已存证"}}
    Evt2{{"侵权线索: 待存证 → 已失效"}}
    Evt3{{"侵权线索: 已存证 → 已立案"}}
```

### 跳转模式说明

- **列表 → 详情**：用户在列表页点击行项目，跳转到详情页查看完整信息
- **列表 → 表单**：用户在列表页点击"新建"按钮，跳转到表单页录入数据
- **详情 → 列表**：用户在详情页点击"返回"，回到列表页
- **任意页 → 主页**：用户点击面包屑或 Logo，返回主页
- **退出登录**：用户点击退出按钮，终止会话

## 分支流程

### 分支一：侵权线索状态流转

```mermaid
graph TD
    S0["待存证"]
    S1["已存证"]
    S2["已失效"]
    S3["已立案"]
    S4["已忽略"]
    S0 -->|一键存证| S1
    S0 -->|超时失效| S2
    S1 -->|发起立案| S3
    S0 -->|判定忽略| S4
```

- **待存证 -> 已存证**：触发=一键存证，条件=命中后 24 小时内完成区块链存证
- **待存证 -> 已失效**：触发=超时失效，条件=超过存证截止时间仍未完成存证
- **已存证 -> 已立案**：触发=发起立案，条件=同一卖家同一专利无在办案件
- **待存证 -> 已忽略**：触发=判定忽略，条件=分析师复核为不侵权或重复线索

### 分支二：存证记录状态流转

```mermaid
graph TD
    S0["存证中"]
    S1["已上链"]
    S2["已失效"]
    S0 -->|上链成功| S1
    S0 -->|存证失败| S2
```

- **存证中 -> 已上链**：触发=上链成功，条件=区块链网络返回存证哈希与时间戳
- **存证中 -> 已失效**：触发=存证失败，条件=上链超时或证据文件缺失

### 分支三：维权案件状态流转

```mermaid
graph TD
    S0["待处置"]
    S1["处置中"]
    S2["平台受理"]
    S3["已结案"]
    S4["已驳回"]
    S0 -->|启动处置| S1
    S1 -->|平台受理| S2
    S2 -->|结案归档| S3
    S1 -->|平台驳回| S4
    S4 -->|补充证据重启| S1
```

- **待处置 -> 处置中**：触发=启动处置，条件=已选定处置策略且跨境案件已绑定当地规则模板
- **处置中 -> 平台受理**：触发=平台受理，条件=平台返回受理回执
- **平台受理 -> 已结案**：触发=结案归档，条件=侵权商品已下架或达成和解
- **处置中 -> 已驳回**：触发=平台驳回，条件=证据不足或权利不稳定
- **已驳回 -> 处置中**：触发=补充证据重启，条件=补充存证后重新提交

### 分支四：跨境规则模板状态流转

```mermaid
graph TD
    S0["已启用"]
    S1["已停用"]
    S0 -->|停用规则| S1
    S1 -->|启用规则| S0
```

- **已启用 -> 已停用**：触发=停用规则，条件=平台投诉渠道变更或规则过期
- **已停用 -> 已启用**：触发=启用规则，条件=规则内容复核通过

## 异常流程

| 异常场景 | 触发条件 | 处理方式 | 提示信息 |
|----------|----------|----------|----------|
| 数据加载失败 | 网络异常或接口超时 | 显示错误状态页，提供重试按钮 | 数据加载失败，请重试 |
| 权限不足 | 用户访问无权限页面或操作 | 路由守卫拦截，跳转 403 页面 | 您无权访问该页面 |
| 数据校验失败 | 表单提交字段不合规 | 表单内联显示校验错误 | 请检查输入内容 |
| 数据不存在 | 访问已删除/不存在的记录 | 显示 404 空状态页 | 该记录不存在或已删除 |
| 并发冲突 | 多人同时编辑同一记录 | 提交时检测版本冲突，提示刷新 | 数据已被他人修改，请刷新后重试 |
