## 1. 验收原则

1. **功能完整性**：所有 PRD 中定义的功能点均需实现并通过验收
2. **数据准确性**：页面展示数据与后端返回数据一致
3. **交互规范性**：操作流程符合 PRD 及 UX 设计规范
4. **异常容错性**：异常场景有友好提示，不出现白屏或崩溃
5. **权限正确性**：各角色权限控制准确无遗漏
