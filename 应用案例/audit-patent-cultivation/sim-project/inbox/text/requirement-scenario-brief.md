# 垂直行业AI高价值专利智能培育平台需求

## 背景
国知局严打低质/非正常专利，企业研发前置创新挖掘工具缺失；通用AI撰写存在大量审查幻觉，高新与专精特新申报强制要求高价值发明专利，亟需面向广州制造/生物医药/AI软件等垂直行业的专利智能培育平台。

## 核心功能
- 细分产业专利知识图谱构建与检索
- AI分层布局方案生成（核心/外围/防御）
- 非正常专利前置筛查与整改提示
- 广州本地高新/专精特新政策资质自动测算
- 创意评分与培育流程追踪

## 用户角色
- 企业IPR：管理创意池，跟踪培育进度，对接代理师
- 代理师：基于培育方案撰写申请，反馈撰写问题
- 研发工程师：提交技术创意，补充技术细节

## 业务规则
- 创意需通过非正常筛查方可进入分析阶段
- AI评分低于60分自动归档为 discarded
- 培育推荐必须绑定产业图谱节点
- 同一企业同行业创意去重，避免重复培育
