# PM 需求详版

> 项目：线上AI智能侵权监测与快速维权取证系统
> 场景：patent-infringement（专利侵权风险监控与维权取证平台）
> 来源：基于 requirement-scenario-brief.md + PM 对话澄清扩展

## 1. 业务背景

### 1.1 行业痛点

线上电商、1688、跨境平台（亚马逊、独立站、TikTok Shop）专利仿冒泛滥，传统维权面临三大痛点：

- **检索周期长**：人工检索一个品牌的涉嫌侵权链接平均需 3-5 个工作日，遗漏率高
- **证据效力弱**：传统截图 + 公证模式成本高（单条 800-2000 元）、出证慢（7-15 天），错过维权黄金期
- **跨境维权门槛高**：欧美 DMCA / Amazon A-to-Z、东南亚 Shopee/Lazada 各有独立投诉规则，律师人工准备材料成本高

### 1.2 政策与市场驱动

- 最高人民法院 2022 年起明确区块链存证可作为电子证据采信，国家知识产权局推动"快维中心"数字化建设
- 海关总署跨境知识产权保护专项行动要求品牌方提供实时监测数据
- 单条区块链存证成本已降至 5-15 元，规模化部署经济性可行

### 1.3 价值主张

构建一站式"AI 监测 + 区块链存证 + 分级维权 + 跨境模板"平台，将单案件维权周期从平均 21 天压缩至 5-7 天，单条存证成本降低 90%，并通过标准化投诉规则模板让中小品牌方具备跨境维权能力。

### 1.4 商业模式

- SaaS 订阅（按品牌数 + 监测 SKU 数计费）
- 存证按量计费（区块链存证调用次数）
- 律师服务撮合（案件升级至律师后按件抽成）

## 2. 用户角色

| 角色 ID | 角色名称 | 职责说明 | 权限范围 |
|---------|---------|---------|---------|
| brand-ipr | 品牌方 IPR | 发起监测任务、跟进维权进度、查看统计报表、分配案件给律师 | 全品牌案件读写导出 |
| lawyer | 维权律师 | 处理已升级的重度侵权案件、输出诉讼方案、生成律师函、上传诉讼材料 | 案件读 + 维权处置写 + 导出，无新建/删除权限 |
| monitor-analyst | 监测分析师 | 执行爬虫监测、完成存证取证、生成标准化取证报告、跟进案件状态 | 案件读 + 存证取证写，无删除/导出权限 |

### 2.1 角色协作流程

1. **品牌方 IPR** 在系统中创建监测任务（绑定品牌 + 专利 + 监测关键词）
2. **监测分析师** 执行爬虫监测，命中后 24 小时内完成区块链存证
3. 高风险案件自动升级至 **维权律师**，律师生成投诉函/律师函
4. **品牌方 IPR** 跟踪维权进度，结案后归档

## 3. 核心功能

### 3.1 侵权案件管理（核心）

- 案件列表（支持按案件编号/平台/卖家/存证状态/律师/品牌方/案件状态搜索）
- 案件详情（含证据快照、区块链存证哈希、维权处置时间线）
- 新建监测表单（绑定品牌、专利、涉嫌卖家、平台）
- 批量存证（多选未存证案件一键发起区块链存证）
- 状态流转：监测中 → 已发现 → 已取证 → 已投诉 → 已结案

### 3.2 多渠道侵权监测（背景能力，非本 Demo 重点）

- 电商爬虫：淘宝、京东、1688、亚马逊、独立站
- 短视频监测：抖音、TikTok
- 展会监测：线下展会现场采集

### 3.3 区块链存证取证

- 商品页面快照（HTML + 截图 + 视频）
- 销售数据快照（销量、评价、价格）
- 区块链哈希上链（司法链 BSN / 杭州互联网法院链）
- 标准化取证报告 PDF 导出

### 3.4 维权分级处置

- **L1 轻度**：平台投诉函（淘宝/京东/亚马逊投诉模板自动填充）
- **L2 中度**：律师函（律师在线编辑生成）
- **L3 重度**：无效检索 + 诉讼前置（律师上传诉讼材料）
- 高风险案件（销量 > 1000 / 评价 > 100）自动升级至 L3

### 3.5 跨境侵权专项（背景能力）

- 欧美投诉规则模板（DMCA / Amazon A-to-Z / USPTO）
- 东南亚投诉规则模板（Shopee / Lazada）
- 多语言投诉函生成

### 3.6 案件统计与报表

- 维权效果统计（成功率、平均周期、挽回金额）
- 渠道分布、平台分布、状态分布
- 律师工作量大屏

## 5. 业务规则

### 5.1 状态流转规则

```
监测中 → 已发现（爬虫命中侵权链接）
       → 已取证（24 小时内完成区块链存证）
       → 已投诉（生成投诉函并发起平台投诉）
       → 已结案（平台下架/卖家和解/诉讼终结）
```

- 监测命中后 **24 小时内必须完成存证**，超时证据效力降低
- 状态只能向前流转，禁止回退（结案后不可重开）
- 高风险案件（销量 > 1000）自动从"已发现"升级至律师处置队列

### 5.2 立案规则

- 同一卖家同一专利 **不可重复立案**（系统校验拦截）
- 跨境案件需绑定当地投诉规则模板（欧美 / 东南亚）
- 案件编号格式：`PAT-YYYYMMDD-NNN`（如 PAT-20260721-001）

### 5.3 权限规则

- 品牌方 IPR 仅查看本品牌案件（数据隔离）
- 律师仅查看分配给自己的案件（自动 + 手动分配）
- 监测分析师可查看全部案件（需执行存证取证）
- 删除案件需品牌方 IPR 二次确认 + 操作日志

### 5.4 存证规则

- 区块链存证调用司法链 BSN 或杭州互联网法院链
- 存证内容：商品页面 HTML 快照 + 截图 + 销售数据 + 时间戳
- 存证哈希写入案件档案，可在详情页查看
- 标准化取证报告 PDF 含：案件信息 + 证据快照 + 区块链哈希 + 取证时间
