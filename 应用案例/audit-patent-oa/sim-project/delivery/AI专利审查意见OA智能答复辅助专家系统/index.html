PROJECT BACKGROUND · 项目背景

AI专利审查意见OA智能答复辅助专家系统

OA 答复拆解、案例匹配、修改推演与标准化输出平台

业务背景 · Business Background

本系统面向 PATENT 领域的核心业务场景。当前AI专利审查意见OA智能答复辅助专家系统旨在通过数字化手段整合OA答复等业务模块，实现数据集中管理、流程标准化与跨角色协作提效。项目定位为：OA 答复拆解、案例匹配、修改推演与标准化输出平台。

核心痛点 · Core Pain Points
  1. 痛点一：OA答复管理缺乏统一系统支撑，数据分散、流程不规范、跨角色协作效率低
解决方案 · Solution Overview

OA 答复拆解、案例匹配、修改推演与标准化输出平台。通过构建PATENT一体化管理平台，实现以下能力：

  • 数据集中化：将OA答复数据统一存储与管理，消除数据孤岛
  • 流程标准化：将核心业务流程（录入、审批、状态流转）固化到系统，减少人为差错
  • 权限精细化：基于 RBAC 模型实现角色-实体-操作三级权限控制，保障数据安全
  • 协作在线化：多角色在线协同，审批流自动流转，提升跨部门协作效率
  • 决策数据化：提供实时数据看板与报表，支撑管理决策

PM 需求详版

本文档由 AI 基于 requirement-scenario-brief.md 与 PM 对话扩展生成。 项目：AI专利审查意见OA智能答复辅助专家系统（patent-oa） 适用范围：代理机构 OA 答复业务全流程，覆盖拆解、匹配、修改推演与标准化输出

1. 业务背景

2026 年发明专利实审驳回率持续走高，新颖性与创造性答复高度依赖代理师个人经验。通用 AI 工具难以结合对比文件的具体评述逻辑，导致答复模板化、答非所问；代理机构人力成本逐年攀升，期限管理混乱引发"逾期视为放弃"事故频发。

本项目面向代理机构与企业 IPR 团队，构建从 OA 接收到答复提交的端到端辅助系统，核心价值：

  • 降本增效：AI 自动拆解 OA 文本（驳回理由 / 对比文件 / 区别技术特征），将单件答复工时从 8 小时降至 3 小时
  • 质量提升：基于同领域答复案例语义匹配，生成分层评述逻辑，避免"答非所问"
  • 风险控制：答复期限 4 个月硬约束 + 期满前 30 天高亮预警，杜绝逾期失权
  • 标准化输出：自动按国知局申报格式排版，减少形式审查退回
  • 全流程留痕：从拆解到提交的每个动作均记录在台账，便于复核与追责

3. 核心功能

3.1 OA 答复案件管理

  • 案件基础信息录入（案件编号、申请号、驳回类型、代理师、答复期限、申请人）
  • 状态流转：已收到OA → 拆解中 → 草拟中 → 已答复 → 已授权 / 最终驳回
  • 期限管理：答复期限 4 个月，期满前 30 天自动高亮预警

3.2 OA 文本智能拆解

  • 自动识别驳回类型（新颖性 / 创造性 / 实用性 / 清晰性）
  • 提取驳回理由段落、对比文件清单、区别技术特征列表
  • 拆解结果以结构化卡片展示，支持代理师编辑修订

3.3 同领域答复案例匹配

  • 基于对比文件 IPC 分类与权利要求主题，语义匹配同领域历史答复案例
  • 分层展示评述逻辑：区别特征认定 → 实际解决技术问题 → 结合启示分析 → 结论反驳
  • 案例库分层：金牌案例（授权）/ 银牌案例（部分授权）/ 铜牌案例（驳回但说理完整）

3.4 权利要求修改智能推演

  • 三种修改策略：删减（删除某项权利要求）、合并（合并从属权利要求）、新增（增加新的从属权利要求）
  • 推演结果按"超范围风险"排序：低风险 / 中风险 / 高风险
  • 修改超范围需经 IPR 复核（强制流程节点）

3.5 答复文件标准化输出

  • 一键按国知局申报格式排版（A4、宋体小四、固定行距）
  • 自动生成答复正文、意见陈述书、修改对照表
  • 支持导出 PDF / DOCX 双格式

3.6 答复全流程台账

  • 时间轴展示：拆解开始时间 / 草稿生成时间 / 提交时间 / 授权或驳回时间
  • 操作日志：每次状态变更记录操作人、时间、变更前后状态
  • 期限提醒：到期前 30 天列表标红 + 站内信推送

4. 页面列表

页面 ID 名称 类型 路由 主要功能
P01 OA答复列表 crud_list /oa-responses 分页展示全部答复案件，支持搜索筛选、新建、查看、导出
P02 OA答复详情 detail_view /oa-responses/:id 展示案件基础信息、AI 拆解结果、答复草稿、操作按钮（按状态显示）
P03 新建答复表单 form_page /oa-responses/form 录入案件基础信息，含表单校验、提交、取消

P01 详细说明

  • 搜索条件：案件编号、申请号、驳回类型、代理师、申请人、状态（6 个搜索字段）
  • 表格列：案件编号、申请号、驳回类型、代理师、答复期限、申请人、状态、操作
  • 操作列：查看（跳转 P02）、导出（已答复状态可点击）
  • 顶部按钮：新建答复（跳转 P03）
  • 期限预警：答复期限 ≤ 30 天的行标红显示

P02 详细说明

  • 详情头部：描述列表展示案件 7 个字段
  • 拆解结果区：展示驳回理由、对比文件列表、区别技术特征列表
  • 答复草稿区：展示分层评述逻辑、权利要求修改推演
  • 操作按钮区（按状态显示）：
  • 已收到OA → 显示"开始拆解"按钮
  • 拆解中 → 显示"生成草稿"按钮
  • 草拟中 → 显示"提交答复"按钮（弹出确认弹窗）
  • 已答复 / 已授权 / 最终驳回 → 不显示操作按钮

P03 详细说明

  • 表单字段：案件编号、申请号、驳回类型（下拉）、代理师、答复期限（日期）、申请人
  • 表单校验：所有字段必填；答复期限不可早于今天；驳回类型必选
  • 提交按钮：保存数据并跳转 P01，状态置为"已收到OA"
  • 取消按钮：返回上一页

5. 业务规则

5.1 状态流转规则

已收到OA → 拆解中 → 草拟中 → 已答复 → 已授权
                                       → 最终驳回
  • 已收到OA → 拆解中：代理师点击"开始拆解"
  • 拆解中 → 草拟中：代理师点击"生成草稿"
  • 草拟中 → 已答复：代理师点击"提交答复"并确认
  • 已答复 → 已授权 / 最终驳回：外部审查结果回填

5.2 期限规则

  • 答复期限 4 个月（自 OA 发文日起算）
  • 期满前 30 天自动高亮预警
  • 逾期视为放弃，案件状态不可再变更

5.3 权限规则

  • 代理师：可创建、读取、更新、删除、导出全部案件
  • 企业IPR：仅可读取、更新本企业案件，不可创建或导出
  • 审查员：仅可读取全部案件，无写入权限
  • 修改超范围需经 IPR 复核（强制流程节点）

5.4 唯一性约束

  • 同一申请号不可重复提交答复（创建时校验）

6.1 P01 OA答复列表

  • [S-15] 默认路由指向 P01（/oa-responses），非 /orders /dashboard /list
