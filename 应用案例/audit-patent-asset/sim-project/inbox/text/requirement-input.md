# PM 需求详版

> 本文档基于 `requirement-scenario-brief.md` 场景简报，经 AI 与 PM 对话澄清后扩展而成。
> 项目名称：专利资产全生命周期数字化价值运营管理平台（slug: patent-asset）

## 1. 业务背景

### 1.1 行业痛点

传统专利台账系统仅完成年费缴纳与基础信息登记，对企业专利资产价值管理存在四大断点：

1. **价值不可量化**：年费台账只记录"是否缴费"，无法回答"这项专利值多少钱"。融资、上市、质押场景缺少标准化专利资产底稿支撑，企业专利资产在资本市场长期处于"沉睡"状态。
2. **生命周期断点**：专利从申请、授权、维持到失效/转让/质押的全生命周期状态分散在不同业务系统中，资产经理难以一览全局，质押中专利是否可转让等合规问题需人工核对。
3. **闲置专利难以盘活**：企业大量有效专利处于"账面有效、实际闲置"状态，缺乏产业撮合通道与价值评估机制，专利变现能力弱。
4. **高管决策缺数据**：C 级管理者无法在驾驶舱中实时查看资产组合估值、状态分布与年费预警，投融资决策缺数据支撑。

### 1.2 价值主张

构建"专利资产全生命周期数字化价值运营管理平台"，以"台账 + 估值 + 质押 + 转让 + 驾驶舱"五位一体能力，将专利从"成本项"转化为"资产项"：

- **数据集中化**：全企业专利资产统一台账，状态变更可追溯
- **估值标准化**：行业定制 AI 估值模型（法律/技术/市场/营收四维评分），季度自动刷新
- **运营在线化**：质押、解除质押、转让全流程在线操作，状态机强约束
- **决策可视化**：高管驾驶舱实时呈现资产组合估值与风险预警
- **底稿一键导出**：投融资尽调、上市申报、质押评估场景一键导出标准化底稿

### 1.3 业务目标 (OKR)

- **Objective**：构建专利资产一体化运营平台，盘活企业专利资产价值
- **KR1**：专利资产数据准确率从 80% 提升至 98%
- **KR2**：覆盖 1 个核心业务实体（专利资产），4 个核心页面（含驾驶舱）
- **KR3**：估值底稿导出效率从 3 工作日缩短至 30 分钟
- **KR4**：高管驾驶舱上线后，C 级管理者可实时查看资产组合估值

### 1.4 不在本期范围（Non-Goals）

- 移动端 App（本期仅做 Web 响应式适配）
- 第三方专利数据源集成（如智慧芽、佰腾网同步，预留接口本期不实现）
- 专利申请流程管理（从提案到授权的 R&D 流程，本期不实现）
- 产业专利撮合交易市场（仅做质押/转让状态跟踪，撮合交易后续迭代）

## 2. 用户角色

### 2.1 企业 IPR（知识产权专员）

- **职责**：维护专利资产台账完整性，跟进年费缴纳与到期预警，发起估值请求
- **权限范围**：全部专利资产的创建、查看、编辑、删除、导出
- **核心场景**：日常在台账列表页查询专利、标记年费到期、提交流转操作（质押/解除/转让）
- **可见页面**：P01 列表 / P02 详情 / P03 估值 / P04 驾驶舱

### 2.2 资产经理

- **职责**：评估专利资产价值，对接融资、上市、质押尽调场景，确认季度估值更新
- **权限范围**：全部专利资产的查看、编辑、导出（不含删除）
- **核心场景**：在估值表单页录入四维评分或调取 AI 估值建议，导出投融资尽调底稿
- **可见页面**：P01 列表 / P02 详情 / P03 估值 / P04 驾驶舱

### 2.3 银行风控

- **职责**：查看质押中专利的估值与风险预警，辅助质押贷款决策
- **权限范围**：仅可查看自有范围内（质押中）专利资产，无写权限
- **核心场景**：在台账列表页筛选质押中专利，进入详情查看估值明细与状态
- **可见页面**：P01 列表 / P02 详情

### 2.4 C 级管理者（CTO/CFO）

- **职责**：通过驾驶舱查看资产组合估值、状态分布、年费预警，支撑投融资决策
- **权限范围**：仅可访问 P04 驾驶舱，按专利权人范围过滤数据
- **核心场景**：季度复盘时打开驾驶舱，切换季度/年度时间范围查看估值趋势

## 3. 核心功能

### 3.1 专利资产台账（P01 列表页）

- 多条件搜索：专利号、专利名称、专利权人、状态、年费到期日
- 数据表格：展示资产列表，状态使用颜色标签（有效/失效/质押中/已转让）
- 年费预警：到期前 30 天高亮提示
- 操作：新增资产、查看资产、导出尽调报告（Excel）
- 分页：底部标准分页组件

### 3.2 资产详情与生命周期操作（P02 详情页）

- 详情头部：描述列表展示专利号、名称、专利权人、状态
- 估值区：估值金额、估值时间、估值模型四维评分（法律/技术/市场/营收）
- 年费区：年费到期日、缴费记录
- 操作按钮区：按状态显示不同操作
  - 有效 → 标记质押 / 转让
  - 质押中 → 解除质押
  - 已转让 / 失效 → 按钮隐藏

### 3.3 资产估值表单（P03 估值页）

- 表单字段：估值金额（必填，>0）、年费到期日（必填）、专利权人
- AI 估值按钮：调用 AI 模型自动填充建议估值（四维评分 → 综合估值）
- 提交：保存数据后返回资产详情页
- 取消：返回上一页，不保存任何修改
- 校验：估值金额 ≤ 0 时高亮错误

### 3.4 高管可视化驾驶舱（P04 Dashboard）

- 顶部 KPI 区：资产总数、总估值、年费预警数、质押数（4 张卡片）
- 状态分布图：饼图展示各状态资产数量分布
- 估值趋势图：折线图展示近 4 季度估值变化
- 时间范围切换器：季度/年度切换按钮
- 权限：仅 C 级与资产经理可访问

## 5. 业务规则

### 5.1 状态机规则

专利资产状态枚举与流转：

- `active` 有效
- `expired` 失效
- `pledged` 质押中
- `transferred` 已转让

**状态流转规则**：

- `active` → `pledged`：标记质押（需 update 权限）
- `pledged` → `active`：解除质押（需 update 权限）
- `active` → `transferred`：转让（需 update 权限 + 转让对象输入弹窗确认）
- `active` → `expired`：年费逾期未缴自动置为失效
- **强约束**：`pledged` 状态不可直接转让，必须先解除质押回到 `active` 才能转让
- **终态**：`transferred`、`expired` 为终态，不可逆

### 5.2 年费规则

- 年费到期前 30 天自动预警，列表页与详情页高亮提示
- 逾期未缴系统自动将状态置为 `expired`
- 缴费记录可在详情页年费区查看

### 5.3 估值规则

- 估值每季度更新一次，需经资产经理确认
- 估值金额必须大于 0，否则表单校验失败
- 提交后更新估值与估值时间戳
- AI 估值建议基于法律/技术/市场/营收四维评分综合计算

### 5.4 权限规则

- 银行风控仅可查看 `pledged` 状态专利，无写权限
- IPR 与资产经理可见全部资产
- 高管驾驶舱仅对 C 级角色与资产经理开放
- 数据按专利权人范围过滤（多权人企业场景）
