## 1. 业务背景

### 1.1 行业现状

全国推行绿色专利快速审查、碳中和产业专项补贴政策，储能、动力电池、氢能、光伏、CCUS、节能装备等新能源赛道企业数量激增。新能源赛道专利壁垒高、全球竞争激烈，但企业普遍缺少垂直赛道情报工具与布局规划能力：

- **专利情报散落**：绿色专利分布在国家知识产权局、EPO、USPTO、WIPO 多个数据库，缺乏面向双碳赛道的垂直聚合视图
- **布局能力薄弱**：企业 IPR 多依赖通用专利工具，难以判断细分赛道的核心/外围/防御布局点，常出现"撒胡椒面"式申请
- **海外风险盲区**：储能、氢能等赛道存在大量标准必要专利（SEP），企业出海前缺乏许可情报监测与风险预警
- **政策响应滞后**：绿色专利快速预审通道要求按赛道分类申报，企业因分类不准确导致预审驳回率高

### 1.2 价值主张

构建双碳赛道专利布局分析与情报监测平台，提供：
1. 垂直聚合的绿色专利数据库（按储能/氢能/光伏/CCUS/节能装备五大细分赛道）
2. 赛道技术演进趋势图谱与空白点预判
3. AI 驱动的布局方案生成（核心/外围/防御三层次）
4. 海外绿色技术许可情报监测与 SEP 风险预警
5. 全球头部企业布局路线梳理

### 1.3 商业模式

- **目标客户**：新能源企业 IP 部门、绿色技术研究院、专利代理机构
- **收费方式**：赛道订阅 + 布局分析按次计费 + 海外情报增值服务

## 5. 业务规则

### 5.1 状态流转规则

专利状态机：`扫描中` → `分析中` → `布局已规划` → `已申请` → `已授权`

- **扫描中 → 分析中**：任意角色点击"发起布局分析"按钮触发
- **分析中 → 布局已规划**：仅布局规划师角色可点击"生成布局方案"按钮
- **布局已规划 → 已申请**：仅企业 IPR 角色可点击"审核通过"按钮
- **已申请 → 已授权**：任意角色可点击"标记授权"按钮
- 状态不可逆，不可跳级

### 5.2 数据权限规则

- 企业 IPR 仅可见本企业专利（按 owner 字段过滤）
- 绿色技术研究员与布局规划师可见全部专利
- 删除操作仅企业 IPR 可执行

### 5.3 业务约束

- 绿色领域必须选择细分赛道（储能/氢能/光伏/CCUS/节能装备），不可为空
- 同一企业同一赛道 6 个月内不可重复发起布局分析（按 owner + green_field + 时间窗口去重）
- 布局方案需经 IPR 审核方可进入申报流程
- 海外许可情报按月推送预警（每月 1 日生成）

### 5.4 表单校验规则

- 专利号：必填，格式为 ZL 开头 + 12 位数字
- 专利名称：必填，长度 5-100 字符
- 绿色领域：必填，单选枚举
- 分析师：必填，长度 2-30 字符
- 企业：必填，长度 2-50 字符
