QUICK START · 三步上手

开始使用 Demora

三步即可上手：选择一个 Desktop Agent，安装 Demora Skill，参考应用案例开始你的第一个项目。每一步都可直接复制粘贴，无需任何编程基础。

STEP 01 · 选择 Desktop Agent

选一个 AI 编程助手

Demora 的 Skill 以通用格式发布，理论上支持任何兼容的 Desktop Agent（AI 编程助手）。我们推荐使用 Trae Work，它与 Demora 的对话式工作流配合最佳。

推荐 Trae Work 国内版 AI 编程助手，支持中文交互，对 Demora 工作流原生兼容 下载 Trae Work →
推荐模型 GLM-5.2（中文需求理解与文档生成表现最佳，推荐模型将不定期更新，敬请关注）
总工作区 建议在 Trae Work 中新建一个独立 workspace 作为 Demora 总工作区，所有项目放在该工作区下，便于统一管理
项目产出 每个项目产出独立的 delivery/<项目名>/ 交付目录，含 Demo + 文档 + 三种下载包，详见 文档
STEP 02 · 安装 Demora Skill

把 Skill 装进你的 Desktop Agent

Skill 是 Demora 的能力载体，安装在 Desktop Agent 后即可让 AI 助手具备 Demora 的需求澄清与 Demo 生成能力。安装方式为通用命令，支持跨 Desktop Agent 复用。

INSTALL · 安装命令（复制粘贴到 Desktop Agent 终端执行）
npx skills add https://demora--ourchem.netlify.app/skills/oc-demora.zip -g -y --agent trae-cn

使用方法：点击「复制」按钮，将命令粘贴到 Desktop Agent 的对话框或终端中直接执行即可完成安装。

↻ 如何更新 Skill
Demora Skill 会持续迭代。每次发布新版本后，重新执行同一条安装命令即可完成更新（命令幂等，会覆盖旧版本）。无需先卸载，也无需手工删除文件。
⇄ 跨 Agent 兼容
npx skills add 是通用的 Skill 安装机制，理论上支持 Trae Work、Cursor、Windsurf 等主流 Desktop Agent。只需根据所用 Agent 调整 --agent 参数即可。
? 安装失败怎么办
常见原因：网络代理拦截、Node.js 版本过低（需 18+）、Desktop Agent 未正确配置 npx 路径。建议先在系统终端单独执行该命令验证网络与权限，再回到 Desktop Agent 重试。

DELIVERY ENTRY · 交付总入口

在你自己的项目里得到同样的交付网站

上面这些案例页面并不是手工搭建的 —— 它们就是 Demora 三阶段流程跑通后的最终交付物。当你按照本页「STEP 01 → STEP 02 → STEP 03 → STEP 04」在自己的项目里完成需求澄清、Demo 生成、评审修订后，只需对 Desktop Agent 说一句「打包交付」，Demora 即会在你的项目目录下生成同样的交付总入口页面：

<你的项目目录>/delivery/<项目名>/index.html

打开这个 index.html，即可获得与上方案例完全一致的交付总入口页面：客户可直接在线浏览 Demo、产品研发团队可下载完整交付包、测试团队可下载文档包。三种角色、一个入口、一键分发。

  1. Phase 1「想清楚」：与 AI 对话澄清需求，锁定需求模型
  2. Phase 2「做精致」：AI 生成可交互 Demo + 自动注入标注 + 生成 PRD 文档
  3. Phase 3「改到位」：评审修订完成后说「打包交付」，自动生成 delivery/<项目名>/index.html
